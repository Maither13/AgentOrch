## 2. 总体结论

**驳回。**

理由：
1. **核心交付缺失**：工作区无 `app/main.py`、无任何路由模块（`app/routers/`、`app/api/` 均不存在）、无 `app/repositories/score_repo.py`。已落盘的只有横切模块（config/db/errors/models/schemas）与 student/course 两个仓储，**没有任何 HTTP 端点**，28 条验收标准无一可被验证。
2. **测试零执行**：`python -m pytest -q` 输出 33 个 skip，`tests/conftest.py:47-50` 的 `_require_app` 因 `from app.main import app` 失败而 skip 全部用例。skip 不构成通过证据。
3. **测试资产不完整**：S5 报告 §4.1 确认 `tests/test_scores.py`、`test_statistics.py`、`test_batch.py`、`test_auth_pagination.py` 未落盘（`file_list` 仅见 `test_students.py`、`test_courses.py`），AC9–AC26、AC28 无测试代码。
4. **已落盘代码存在与设计契约不一致的缺陷**（见阻断项 3、4），即使补齐路由也会导致 AC10/AC20 失败。

## 3. 阻断项清单（P0）

**B1. 应用入口与路由层完全缺失**
- 复现：`file_list` 结果中无 `app/main.py`；`app/` 下仅 `__init__.py`、`config.py`、`db.py`、`errors.py`、`models.py`、`schemas.py`、`repositories/{__init__,course_repo,student_repo}.py`。
- 影响：AC1–AC28 全部无法验证。
- 修复：交付 `app/main.py`（FastAPI 实例、`AppError` 异常处理器、鉴权依赖、路由注册）及 students/courses/scores/statistics/transcript/batch 全部路由模块。

**B2. `app/repositories/score_repo.py` 未落盘**
- 复现：`file_list` 中不存在该文件；S5 报告 §0 指出 S3 文本中该文件内容被截断（`aggregate_by_class` 的 `join` 之后缺失）。
- 影响：AC9–AC25 全部依赖成绩仓储。
- 修复：重新交付完整文件。

**B3. `ux_scores_active_triplet` 为全量唯一索引，违反“仅未删除记录唯一”契约**
- 证据：`app/models.py:88-95`，`sqlite_where=None, postgresql_where=None`。
- 影响：AC10 的“记录数仍为 1”可通过，但逻辑删除后重新录入同一 `(student_id, course_id, semester)` 会被索引拒绝，与需求 §5.3 及裁决 C7 冲突。
- 修复：改为 `sqlite_where=text("is_deleted = 0")`（Postgres 同理），或改为应用层校验。

**B4. `aggregate_by_course` 使用 `func.case(...)`**
- 证据：S5 报告 §4.3 记录 S3 文本中该写法；SQLAlchemy 2.0 中 `func.case` 会生成非法 SQL。
- 影响：AC20/AC21 统计接口必然 500。
- 修复：改为 `from sqlalchemy import case` 后使用 `case(...)`。

**B5. 测试资产缺失，无法形成验收证据**
- 复现：`file_list` 仅见 `tests/conftest.py`、`tests/test_students.py`、`tests/test_courses.py`；`test_runner` 输出 33 skip。
- 影响：AC9–AC26、AC28 无测试覆盖，按规则直接判 failed。
- 修复：转存并补全 S4 文本中的 4 个测试文件（`test_statistics.py` 尾部被截断于 `params={"semester": "202`），并安装 `sqlalchemy`（`requirements.txt` 已声明但环境缺失）。

**B6. 鉴权（F12/AC26）无任何实现**
- 证据：`tests/conftest.py:36-39` 定义 `token-admin`/`token-teacher`/`token-student-1`/`token-student-2`，但工作区无任何代码读取 `Authorization` 头；`app/errors.py:17-18` 仅定义 `UNAUTHORIZED`/`FORBIDDEN` 枚举。
- 影响：AC26 无法通过；且所有接口当前无鉴权保护，属安全阻断。
- 修复：实现 Bearer Token 依赖 + 学生角色越权 403 判定。
